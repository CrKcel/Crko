## 功能

底部三栏：**日程**（左）、**今日**（中）、**更多**（右）。

| 页面 | 内容 |
| --- | --- |
| 今日 | 日期与能量、今天三件事、下一步卡与 5 分钟启动、「我动不了」、一行速记、完整待办池与已完成折叠、专注计时 |
| 日程 | 周日期条、日/周时间轴、日/周列表、月历、日程编辑与重复规则 |
| 更多 | 统计、手帐、日历与数据、设置页 |

### 今日

- **今天三件事**：最多选 3 个根任务；不选也随时可以开始。
- **下一步卡**：显示第一件未完成的事；「开始 5 分钟」两次确认后进入 3-2-1 倒数与 5 分钟专注，「我动不了」提供拆更小一步、先做 2 分钟、先做别的、今天到这四个分支。
- **能量**：低能量时下一步优先估时不超过 10 分钟的任务。
- **速记**：一行输入直接进入待办池。
- **待办池**：优先级、日期、进度、备注、子任务、系列操作与已完成折叠任务。
- **专注**：暂停、继续、提前结束；进程被杀后按壁钟恢复；结束只询问是否完成，不自动完成。

### 日程

上方为当周日期条，下方展示所选日期（默认今天）的日程。

**时间轴**

- 00:00–24:00，每小时一格；点击空白时段新建日程。
- 竖向可无限上下滚动，跨过 00:00/24:00 即无缝衔接到上一天/下一天。
- 每天以日期标题分块；标题滚动时吸顶，跨天时由下一天的标题接替。
- 横向滑动切换到列表视图。

**列表**

- 一次展示一天，左右滑动切换相邻日期，页内竖向滚动。
- 在顶部继续下拉、在底部继续上拉（内容不足一屏时直接竖滑）可切回时间轴。

**周历与月历**

- 星期栏固定在顶部。
- 下拉日期区时，整月网格以本周为锚点上下展开；上滑收起，也可点击箭头切换。
- 左右滑动切换月份。

**整周总览**

- 通过视图菜单或下方区域双指捏合进入，双指张开退回日视图。
- 同样支持两种形式：
  - **时间轴**：七列，一页一周；页内先竖向滚动，滚到顶部/底部后继续滑动翻到上/下一周；星期日期条固定在顶部跟随。
  - **列表**：一次一周，左右滑动切换相邻周，页内竖向滚动。
- 两种形式之间可横向/竖向滑动切换，上方周历不受影响。

**周历联动**

- 时间轴滚动时，上方周历实时跟随当前所在的天/周；换周时保持所选星期。
- 列表视图左右滑动跨周时，上方周历同步滑动，停靠后再更新所选日期。

**新建与编辑**

- 可用周日期条点选本周任意一天，也可打开月历自选其他日期。
- 可设置全天、跨天/多天、截止到午夜，以及地点、分类、状态、优先级、提醒等属性。
- 重复支持每天、每周、每月、每年与自定义星期，并可设置间隔、次数或结束日期。
- 编辑重复日程时，可选择“仅此次 / 此次及以后 / 整个系列”。

### 更多

- **统计**：今日完成、进行中、未来三天日程、近七天完成量、按优先级分布。
- **日历与数据**：
  - **日历**：新建、重命名、配色、隐藏/显示、设为默认；删除前确认并显示记录数量，最后一个本地日历不可删除；某个日历可单独导出。
  - **日程数据**：导入导出。日程与待办一起导出为 `.ics` 文件，也可从其他日历应用导入。全天/多日事件、时区、重复规则与例外日期、提醒及常见 VEVENT 属性会尽量保留。
  - **日历订阅**：订阅 webcal/ICS 日历源并同步。
  - **云同步**：本地日历的日程/待办/手帐与应用设置在多台设备间端到端加密同步——密码派生密钥，服务器只存密文，无法读取内容。

## 设置

- **语言**：中文/英文。
- **外观**：浅色/深色。
- **配色**：莫奈、无配色、自选色盘。
- **时间线**：日程页滚动起始小时。
- **提醒**：App 主动提示的每日上限（关闭 / 3 / 6）；用户自己设置的闹钟不受影响。
- **云同步**：账号注册/登录、每设备开关、立即同步、退出登录与注销云端账号。
